# Скриншейдер на Python

Программа для создания скриншотов по нажатию `Print Screen` с возможностью выбора области.

## Структура

```ini
[Settings]
save_path = C:\Users\User\Documents\Screenshots
behavior = save_file

[Quality]
format = PNG
quality = 95
compression = 6

[Appearance]
overlay_alpha = 0.3
selection_color = red
selection_width = 2
```

## Настройка

### [Settings] - Общие настройки

┌───────────┬────────────────────┬─────────────────────────────────────┐
│ Параметр  │ Значения           │ Описание                            │
├───────────┼────────────────────┼─────────────────────────────────────┤
│ save_path │ любой путь к папке │ Куда сохранять скриншоты            │
├───────────┼────────────────────┼─────────────────────────────────────┤
│ behavior  │ save_file          │ save_file - сохранять в файл        │
│           │ copy_clipboard     │ copy_clipboard - копировать в буфер │
└───────────┴────────────────────┴─────────────────────────────────────┘

### [Quality] - Настройки качества

┌─────────────┬───────────┬────────────────────────────────────────────────────────────┐
│ Параметр    │ Значения  │ Описание                                                   │
├─────────────┼───────────┼────────────────────────────────────────────────────────────┤
│ format      │ PNG, JPEG │ Формат изображения                                         │
├─────────────┼───────────┼────────────────────────────────────────────────────────────┤
│ quality     │ 1-100     │ Качество JPEG (выше = лучше качество, больше размер)       │
├─────────────┼───────────┼────────────────────────────────────────────────────────────┤
│ compression │ 0-9       │ Сжатие PNG (0 = без сжатия/макс качество, 9 = макс сжатие) │
└─────────────┴───────────┴────────────────────────────────────────────────────────────┘

PNG: compression = 0 → максимальное качество, большой файл
PNG: compression = 6 → хороший баланс (по умолчанию)
PNG: compression = 9 → минимальный размер, чуть медленнее
JPEG: quality = 100 → отличное качество
JPEG: quality = 85 → хороший баланс
JPEG: quality = 70 → меньше размер, заметны потери

### [Appearance] - Внешний вид выделения

┌─────────────────┬────────────────────────────────────────┬─────────────────────────────────────────────────────────────────────────────┐
│ Параметр        │ Значения                               │ Описание                                                                    │
├─────────────────┼────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────┤
│ overlay_alpha   │ 0.1 - 0.9                              │ Прозрачность затемнения экрана (0.1 = почти прозрачный, 0.9 = почти чёрный) │
├─────────────────┼────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────┤
│ selection_color │ red, green, blue, yellow, white, black │ Цвет рамки выделения                                                        │
├─────────────────┼────────────────────────────────────────┼─────────────────────────────────────────────────────────────────────────────┤
│ selection_width │ 1-10                                   │ Толщина рамки в пикселях                                                    │
└─────────────────┴────────────────────────────────────────┴─────────────────────────────────────────────────────────────────────────────┘
