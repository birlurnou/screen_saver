# Скринсейвер на Python

Программа для создания (копирование, сохранения) скриншотов по нажатию `назначенного хоткея` с выбором области и места для хранения.

## Структура (дефолтные настройки)

```ini
[Settings]
save_path = C:\Users\User\Documents\Screenshots
save = 1
copy = 1

[Hotkeys]
screenshot_hotkey = alt+z+x

[Quality]
format = PNG
quality = 95
compression = 6

[Appearance]
overlay_alpha = 0.2
overlay_color = black
selection_color = black
selection_width = 1
cursor_type = tcross
```

## Настройка

### [Settings] - Общие настройки

```
┌───────────┬──────────┬───────────────────────────────────────────┐
│ Параметр  │ Значения │ Описание                                  │
├───────────┼──────────┼───────────────────────────────────────────┤
│ save_path │ C:\path  │ путь для сохранения, автогенерируемый     │
├───────────┼──────────┼───────────────────────────────────────────┤
│ save      │ 0-1      │ 0 → не сохранять, 1 → сохранять в файл    │
├───────────┼──────────┼───────────────────────────────────────────┤
│ copy      │ 0-1      │ 0 → копировать, 1 → не копировать в буфер │
└───────────┴──────────┴───────────────────────────────────────────┘
```

### [Quality] - Настройки качества

```
┌─────────────┬───────────┬──────────────────────────────────────┐
│ Параметр    │ Значения  │ Описание                             │
├─────────────┼───────────┼──────────────────────────────────────┤
│ format      │ PNG, JPEG │ Формат изображения                   │
├─────────────┼───────────┼──────────────────────────────────────┤
│ quality     │ 1-100     │ Качество JPEG                        │
│             │           │ Выше → лучше качество, больше размер │
├─────────────┼───────────┼──────────────────────────────────────┤
│ compression │ 0-9       │ Сжатие PNG                           │
│             │           │ 0 → без сжатия/макс качество         │
│             │           │ 9 → макс сжатие                      │
└─────────────┴───────────┴──────────────────────────────────────┘
```
```
PNG: compression = 0 → максимальное качество, большой файл
PNG: compression = 6 → хороший баланс (по умолчанию)
PNG: compression = 9 → минимальный размер, чуть медленнее
JPEG: quality = 100 → отличное качество
JPEG: quality = 85 → хороший баланс
JPEG: quality = 70 → меньше размер, заметны потери
```

### [Appearance] - Внешний вид выделения

```
┌─────────────────┬────────────┬────────────────────────────────┐
│ Параметр        │ Значения   │ Описание                       │
├─────────────────┼────────────┼────────────────────────────────┤
│ overlay_alpha   │ 0.1 - 0.9  │ Прозрачность затемнения экрана │
│                 │            │ 0.1 → почти прозрачный         │
│                 │            │ 0.9 → почти чёрный             │
├─────────────────┼────────────┼────────────────────────────────┤
│                 │ black      │                                │
│ overlay_color   │ white      │ Цвет затемнения экрана         │
│                 │ red        │                                │
├─────────────────┤ green      ├────────────────────────────────┤
│                 │ blue       │                                │
│ selection_color │ yellow     │ Цвет рамки выделения           │
│                 │ purple     │                                │
├─────────────────┼────────────┼────────────────────────────────┤
│ selection_width │ 1-10       │ Толщина рамки в пикселях       │
├─────────────────┼────────────┼────────────────────────────────┤
│ cursor_type     │ tcross     │ Тип курсора                    │
│                 │ cross      │                                │
│                 │ plus       │                                │
│                 │ hand2      │                                │
│                 │ pencil     │                                │
│                 │ dotbox     │                                │
│                 │ target     │                                │
└─────────────────┴────────────┴────────────────────────────────┘
```
