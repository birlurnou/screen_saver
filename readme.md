# Скринсейвер на Python

Программа для создания (копирования, сохранения) скриншотов по нажатию `назначенного хоткея` с выбором области и места для хранения, с перечнем расширенных настроек.

## Структура (дефолтные настройки)

```ini
[Settings]
save_path = C:\Users\{User}\Documents\Screenshots
extension_path = 
filename_mask = _ymd-hMs
datetime_structure = 1
save = 1
copy = 1

[Hotkeys]
screenshot_hotkey = alt+z+x

[Quality]
format = PNG
quality = 100
compression = 0

[Appearance]
overlay_color = black
overlay_alpha = 0.4
selection_border_color = black
selection_border_width = 1
selection_fill_color = white
cursor_type = tcross
```

## Настройка

### [Settings] - Общие настройки

```
┌────────────────────┬──────────┬────────────────────────────────────────────────────────┐
│ Параметр           │ Значения │ Описание                                               │
├────────────────────┼──────────┼────────────────────────────────────────────────────────┤
│ save_path          │ C:\path  │ путь для сохранения, автогенерируемый                  │
├────────────────────┼──────────┼────────────────────────────────────────────────────────┤
│ extension_path     │ \example │ расширенный путь (необязательно, есть save_path)       │
├────────────────────┼──────────┼────────────────────────────────────────────────────────┤
│ filename_mask      │ ymd_hMs  │ маска имени файла, можно использовать символы ymdhMs_- │
├────────────────────┼──────────┼────────────────────────────────────────────────────────┤
│ datetime_structure │ 0-1      │ 0 → не структурировать, 1 → структурировать директорию │
├────────────────────┼──────────┼────────────────────────────────────────────────────────┤
│ save               │ 0-1      │ 0 → не сохранять, 1 → сохранять в файл                 │
├────────────────────┼──────────┼────────────────────────────────────────────────────────┤
│ copy               │ 0-1      │ 0 → копировать, 1 → не копировать в буфер              │
└────────────────────┴──────────┴────────────────────────────────────────────────────────┘
```

### [Quality] - Настройки качества

```
┌─────────────┬───────────┬──────────────────────────────────────┐
│ Параметр    │ Значения  │ Описание                             │
├─────────────┼───────────┼──────────────────────────────────────┤
│ format      │ PNG, JPEG │ Формат изображения                   │
├─────────────┼───────────┼──────────────────────────────────────┤
│ quality     │ 1-100     │ Качество JPEG                        │
│             │           │ Выше → лучше качество, больше размер │
├─────────────┼───────────┼──────────────────────────────────────┤
│ compression │ 0-9       │ Сжатие PNG                           │
│             │           │ 0 → без сжатия/макс качество         │
│             │           │ 9 → макс сжатие                      │
└─────────────┴───────────┴──────────────────────────────────────┘
```
```
PNG: compression = 0 → максимальное качество, большой файл
PNG: compression = 6 → баланс
PNG: compression = 9 → минимальный размер, плохое качество
JPEG: quality = 100 → отличное качество
JPEG: quality = 85 → баланс
JPEG: quality = 70 → плохое качество
```

```
┌────────────────────────┬────────────┬────────────────────────────────┐
│ Параметр               │ Значения   │ Описание                       │
├────────────────────────┼────────────┼────────────────────────────────┤
│ overlay_alpha          │ 0.1 - 0.9  │ Прозрачность затемнения экрана │
│                        │            │ 0.1 → почти прозрачный         │
│                        │            │ 0.9 → почти чёрный             │
├────────────────────────┼────────────┼────────────────────────────────┤
│ overlay_color          │ black      │ Цвет затемнения экрана         │
│ selection_border_color │ white      │ Цвет рамки выделения           │
│ selection_fill_color   │ red        │ Цвет фона выделения            │
│                        │ green      │                                │
│                        │ blue       │                                │
│                        │ yellow     │                                │
│                        │ purple     │                                │
├────────────────────────┼────────────┼────────────────────────────────┤
│ selection_width        │ 1-10       │ Толщина рамки в пикселях       │
├────────────────────────┼────────────┼────────────────────────────────┤
│ cursor_type            │ tcross     │ Тип курсора                    │
│                        │ cross      │                                │
│                        │ plus       │                                │
│                        │ hand2      │                                │
│                        │ pencil     │                                │
│                        │ dotbox     │                                │
│                        │ target     │                                │
└────────────────────────┴────────────┴────────────────────────────────┘
```

## Установка

### Установка Модулей

```ini
pip install -r requirements.txt
```

### Параметры для Action в Task Scheduler (для запуска .py)

```ini
C:\Users\{User}\AppData\Local\Programs\Python\Python313\pythonw.exe
C:\path\to\folder\main.py
C:\path\to\folder\
```

### Параметры для Action в Task Scheduler (для запуска .exe)

```ini
C:\path\to\folder\main.exe
-
C:\path\to\folder\
```
